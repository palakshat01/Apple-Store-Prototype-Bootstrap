# 🍎 Apple Store Website Prototype

A responsive **Apple Store website prototype** built using **HTML5 and Bootstrap 5**.  
This project is created as a frontend practice project to demonstrate Bootstrap components and responsive web design.

## 🚀 Features

- 🧭 Responsive Bootstrap Navbar
- 🏠 Home Page
- 🔥 Trending Page
- 📞 Contact Page
- 🔍 Search Bar
- 🖼️ Bootstrap Carousel
- 📱 Product Cards
- 💻 iPhone and MacBook product sections
- 🔐 Login Form
- 📝 Sign Up Form
- 🪟 Bootstrap Login & Signup Modals
- 📱 Responsive layout for different screen sizes
- 🎨 Bootstrap styling and components

## 🛠️ Technologies Used
- Bootstrap 5.3.8

## 📦 Bootstrap Components Used

This project uses several Bootstrap components, including:

- Navbar
- Carousel
- Cards
- Forms
- Buttons
- Modals
- Footer
- Utility Classes
